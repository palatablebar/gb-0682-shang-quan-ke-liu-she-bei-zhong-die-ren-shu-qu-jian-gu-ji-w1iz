# 场景与反例

12小时观测，每小时三处设备、三组两两重叠记录。首小时A120、B110、C90，交集40、30、20，可行联合人数230至250。A100、B80、交集30时联合人数150。A、B、C都100但AB80、AC80、BC0，无可行三方交集，必须隔离。脏样例含缺测、同版冲突、BOM、短行、重复与中文换行。

conflict.csv 给出两类矛盾桶：10:00（+08:00，UTC 02:00）三方交集无可行整数，11:00（UTC 03:00）交集超出 min(A,B)。两桶不相邻且各自整桶隔离，形成两张待检工单，每张含桶内6台设备、冲突依据与受影响区间；正常桶照常估界。补录修正其中一个桶后，仅该桶被重判，对应工单转已解除，另一张工单与派单记录原样保留。
